# 결과 화면과 공유 카드 v002 적용 요청

2026-11-21 디자인 승인. Cursor에서 구현·검증한다. [결과 카드 시안](../design/life_tactics/v002/result_tr01_v002.png), [마커 배치 예시](../design/life_tactics/v002/ground_tr01_v002.png), [빈 전술판 원본](../design/life_tactics/v002/tactics_board_v002.png)을 기준으로 작업한다. 19번 요청서의 좌우 순서와 카드 숫자 배지는 이번 승인안으로 대체한다.

## 적용

1. 빈 전술판 PNG를 모서리 투명도가 유지되는 WebP로 변환해 앱에 등록하고 LifeTacticsArt.tacticsBoard에서 참조한다. 마커는 jersey_marker_v001.webp를 재사용한다.
2. pilot_pages.dart의 공통 TacticsBoard에서 마커 너비·높이를 각각 전술판 너비의 0.09에서 0.135로 변경한다. 마커 행은 LifeTacticsArt.markerRows(result.formation)로 생성한다. 위에서부터 공격·중원·수비 순서다. 결과 화면과 공유 카드에서 이 위젯을 공유한다.
3. PilotResultPage의 _ResultLine은 사이다 왼쪽, 전술판 오른쪽 순서로 한 행을 구성한다. 모바일과 PC 모두 콘텐츠 폭 안에서 두 그림과 마커가 잘리지 않도록 비율을 유지한다. 결과 제목·긍정 설명·점수·행동 요약은 기존 데이터를 표시한다.
4. PilotSharePage에서 현재 결과를 LifeTacticsShareCard에 전달한다. 카드 상단 경기장 위에 사이다를 왼쪽, 전술판을 오른쪽에 놓고 기존 포메이션 숫자 배지는 제거한다. 1080×1080 시안 기준 사이다 이미지 박스는 (86,145)에서 450×450, 전술판은 (615,158)에서 344×430이다. 카드 폭 기준으로 비례 축소한다. 이 좌표에는 사이다 에셋 자체의 투명 여백이 포함된다. 제목·캐치프레이즈·긍정 설명·브랜드 문구는 현재 언어로 렌더링한다.
5. 완성 PNG 두 장은 시각 비교용이다. 앱에서 10종 모두 실제 결과 타입의 사이다와 포메이션을 조합한다. tr06·tr10은 D.C 로고 v003, 나머지는 v002다. 접근성 트리에는 포메이션을 한 번 읽을 수 있는 레이블을 제공하고 개별 장식용 마커의 반복 낭독을 피한다.

## 검증

- 10개 결과의 세 행과 마커 합계 10을 위젯 테스트로 확인한다. tr01은 위에서 4·2·4, 비대칭 tr07(6-3-1)은 1·3·6이다. 6개 마커가 한 행에 들어가는 경우의 간격도 확인한다.
- D:\AppYou\app에서 flutter analyze와 flutter test를 실행한다. Chrome에서는 모바일 360px 및 PC 폭으로 결과 화면과 공유 카드의 좌우 순서, 모서리 투명도, 이미지 겹침·잘림을 확인한다. 대표 결과로 두 화면을 캡처해 승인 시안과 비교하고 실행 결과와 미검증 항목을 보고한다.
