# 모바일·PC 참여 흐름
이 문서는 화면별 역할과 검증 기준을 정한다. 레이아웃 수치와 컴포넌트는 [UI 디자인 시스템 v1.0](09_UI_DESIGN_SYSTEM.md), 캐릭터는 [사이다 가이드](08_SAIDA_CHARACTER.md)를 따른다.

|화면|사용자가 보는 내용|동작·상태|
|---|---|---|
|홈·소개|검사명, 짧은 설명, 사이다, 문항 수|데이터가 준비되면 이미지가 내려받는 중에도 제목·설명·시작하기를 보여 준다. 경기장과 사이다는 같은 크기의 크림색 자리를 유지하고, 홈 이미지에는 로딩 문구를 두지 않는다.|
|문항|한 화면에 한 문항, 다섯 응답, 현재/전체 진행률|응답 선택 상태는 색과 표식으로 구분한다. 이전으로 돌아가면 선택을 복원하고 변경하면 점수를 다시 계산한다. 마지막 문항의 다음 동작은 결과 보기다.|
|사이다 안내|시작·절반·마지막·결과 공개 때의 대사와 표정|응답을 칭찬·평가해 특정 선택을 유도하지 않는다. 표정이 없어도 대사와 진행률로 상태를 이해할 수 있게 한다.|
|결과|별명, 포메이션, 한 줄 문구, 설명, 세 축 점수, 사이다의 마무리 대사|결과명과 설명을 먼저 보여 준다. 사이다·전술판·마커가 400ms 안에 오면 안내 없이 표시하고, 더 걸리면 그림 영역에 로딩 문구를 한 번 둔다. 실패하면 다시 시도를 표시하고 현재 결과는 유지한다. 수비·중원·공격 라인 왼쪽에 행복·의미·심리적 풍요로움을 고정해 표시한다. 포메이션 숫자는 실제 배치에서 읽고, 세 축은 각각 자신의 범위에서 표시하며 점수 합을 100%로 만들지 않는다. 타입 설명 뒤, 공유 버튼 바로 위에 사이다가 같은 대사를 한 번 건넨다.|
|공유|결과 카드, 링크 공유, 카카오톡 피드, 이미지 저장|일반 공유는 결과명과 진단 링크를 보낸다. 카카오톡 인앱에서는 현재 결과와 언어에 맞는 공개 카드 이미지와 같은 진단 링크를 피드로 보낸다. 공유와 닫기는 이미지 저장 준비를 기다리지 않는다. 카카오톡 공유가 실패하면 다시 시도와 링크만 공유하기를 제공한다.|

좁은 세로 화면에서는 선택지와 버튼을 한 열에 둔다. 긴 문항과 번역은 줄바꿈과 세로 스크롤을 허용하며 답변·하단 버튼이 가려지지 않아야 한다. PC에서는 중앙 읽기 영역 안에 문항과 선택지를 유지한다. 키보드로 답을 고르고 다음·이전으로 이동할 수 있어야 한다. 모션 감소 설정에서는 정적인 표정 전환으로 진행한다. 검증 시 모바일 세로와 데스크톱에서 긴 문구, 큰 글씨, 뒤로 이동, 공유 실패 후 복사를 각각 확인한다.


## 결과 타입별 설명과 사이다

포메이션과 사이다 아래, 점수표 위에 결과별 캐치프레이즈와 설명을 표시한다. ResultTypeId로 찾은 ResultTypes 행의 CatchphraseKey와 DescriptionKey를 현재 언어로 해석한다. 긴 번역은 줄바꿈하고 결과 화면 전체를 스크롤한다. 그 설명과 점수·장면 요약을 읽은 다음, 공유 버튼 바로 위에서 사이다의 윙크 초상이 왼쪽 꼬리 말풍선으로 같은 대사를 건넨다. 결과 상단의 미리보기 판정 문구는 두지 않는다. 공유로 가는 버튼은 “공유 카드 보기”이다. 대사는 10개 타입이 같고, 말풍선 높이는 글자에 맞춘다. 결과 전술판과 공유 카드의 사이다는 [타입별 승인 버전](08_SAIDA_CHARACTER.md)을 따른다. 공유 카드 미리보기와 저장 이미지는 타입별 캐치프레이즈와 설명을 유지하고 이 말풍선은 넣지 않는다. 시안은 design/ui_review/look_at_you_mobile_v003.html에 있다. 첫 파일럿의 공유 영역은 [카드 미리보기](17_LIFE_TACTICS_PILOT_FLOW.md)까지 제공한다.

2026-11-21 · [결과·공유 카드 v002 승인](21_RESULT_CARD_V002_CURSOR_REQUEST.md). 두 화면 모두 사이다는 왼쪽, 라운드 전술판은 오른쪽에 배치한다. 마커 한 변은 전술판 폭의 13.5%이며 공유 카드의 숫자 배지를 마커 배치로 대체한다.

2026-11-21 · 포메이션 가독성. 결과 화면은 “{formation} 포메이션”과 전술판을 둥근 테두리 안에 둔다. 왼쪽 세 줄은 위부터 심리적 풍요로움, 의미, 행복이며 한 줄로 둔다. 인원 요약과 긴 안내 문장은 결과 화면에 두지 않는다. 공유 카드는 포메이션 제목과 숫자 없는 한 줄 라벨만 두고, 하단 초대 문구는 넣지 않는다. 카드의 축구장 사진과 블러는 사이다와 전술판이 있는 영역에만 둔다.
