# 모바일·PC 참여 흐름
이 문서는 화면별 역할과 검증 기준을 정한다. 레이아웃 수치와 컴포넌트는 [UI 디자인 시스템 v1.0](09_UI_DESIGN_SYSTEM.md), 캐릭터는 [사이다 가이드](08_SAIDA_CHARACTER.md)를 따른다.

|화면|사용자가 보는 내용|동작·상태|
|---|---|---|
|홈·소개|검사명, 짧은 설명, 사이다, 문항 수|공개 가능한 테스트만 표시. 시작 전에 진행 분량을 알려 준다.|
|문항|한 화면에 한 문항, 다섯 응답, 현재/전체 진행률|응답 선택 상태는 색과 표식으로 구분한다. 이전으로 돌아가면 선택을 복원하고 변경하면 점수를 다시 계산한다. 마지막 문항의 다음 동작은 결과 보기다.|
|사이다 안내|시작·절반·마지막·결과 공개 때의 대사와 표정|응답을 칭찬·평가해 특정 선택을 유도하지 않는다. 표정이 없어도 대사와 진행률로 상태를 이해할 수 있게 한다.|
|결과|별명, 포메이션, 한 줄 문구, 설명, 세 축 점수|수비·중원·공격 라인과 각 축 이름을 함께 표시한다. 세 축은 각각 자신의 범위에서 표시하고 점수 합을 100%로 만들지 않는다.|
|공유|결과 이미지 미리보기, 카카오톡, 저장, 링크 복사|실패하면 링크 복사를 제공한다. 공유받은 화면에는 같은 테스트를 시작하는 버튼을 둔다.|

좁은 세로 화면에서는 선택지와 버튼을 한 열에 둔다. 긴 문항과 번역은 줄바꿈과 세로 스크롤을 허용하며 답변·하단 버튼이 가려지지 않아야 한다. PC에서는 중앙 읽기 영역 안에 문항과 선택지를 유지한다. 키보드로 답을 고르고 다음·이전으로 이동할 수 있어야 한다. 모션 감소 설정에서는 정적인 표정 전환으로 진행한다. 검증 시 모바일 세로와 데스크톱에서 긴 문구, 큰 글씨, 뒤로 이동, 공유 실패 후 복사를 각각 확인한다.
