# 나의 인생 전술 · 기본 문항 편집 0.4.0

기본 문항 18개 중 16개를 새 ID로 교체했다. 기존 6번·10번은 같은 문장과 ID로 비교한다. 기존 1~18번과 새 표시 순서는 아래 표에서 대조한다. H/M/R 반복 순서를 풀었고 축별 여섯 문항, 정방향 5점, 가중치와 상황 선택 여섯 장면은 기존과 같다. 사용자에게는 축 이름과 점수 방향을 문항 옆에 표시하지 않는다. 한국어 파일럿 초안이다.

## 파일럿 적용

Cursor에서 미리보기 기본 버전을 0.4.0으로 바꾸고 pubspec.yaml에 0.4.0의 카탈로그·문항·언어·상황 파일을 등록한다. 0.3.0 고정 문항 ID와 원래 순서로 작성한 31개 회귀 사례는 0.3.0에 고정한다. 새 버전은 18+6 완주, 언어 폴백, 전체 4점 → 세 축 75점 및 tr10, 상황 선택 별도 집계를 확인한다. 구버전 회차는 원래 버전에서 해석한다.

실사용 비교에서는 문항별 4·5번 응답 수와 전체 응답 수, 선택 이유, 답하면서 예상한 전술을 함께 기록한다. 모임·취미 경험 유무 때문에 답이 갈렸는지도 묻는다. 문장 편집만으로 실제 분별력 향상이나 유형 분포 변화가 확인된 것은 아니다.
