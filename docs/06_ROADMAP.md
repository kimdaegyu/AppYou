|단계|상태|현재 근거와 다음 완료 조건|
|---|---|---|
|1. Flutter 및 Git 기반|완료(초기 구성)|Web·Android 프로젝트와 초기 Git 커밋, origin 설정 확인. 정적 분석·웹 빌드 성공 기록이 있다. 일반 PC Chrome 실행과 위젯 테스트 통과 기록은 별도 확인 대상이다.|
|2. Excel 원본 데이터 설계|진행 중|0.2.0은 검수 전이다. 0.3.0은 추천 18문항과 미리보기 규칙을 추가했지만 번역·판정은 아직 draft/pending이다.|
|3. Python JSON 직렬화|완료(직렬화)|0.2.0 schema 1과 0.3.0 schema 2를 함께 생성한다. 같은 입력의 반복 생성, 실패 시 기존 파일 보존을 테스트했다. 두 버전의 출시 진단은 0개다.|
|4. Flutter 공통 엔진|완료(미리보기 파일럿)|응답 수정, 역채점, 독립 가중 평균, 12/20 판정을 위젯 없는 Dart로 구현했다. pending 규칙은 미리보기 세션만 실행한다. 출시 판정은 승인 전이라 막혀 있다.|
|5. 사이다 UI와 첫 진단|진행 중|개발 미리보기에서 파일럿 문항을 끝까지 진행해 점수와 결과 ID를 본다. 제품 진입점과 결과 전용 화면은 아직 없다.|
|6. 결과 및 공유|미착수|전술 화면, 언어별 이미지, 카카오톡·저장·링크 및 공유받은 경로 검증.|
|7. 글로벌 검증 및 출시|미착수|출시 언어 검수, 구버전 링크, 실제 기기와 브라우저 점검 후 배포.|
