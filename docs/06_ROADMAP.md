# 개발 로드맵
2026-11-21 기준. 문서와 데이터 초안 작성, 코드 구현, 실제 실행 검증을 구분한다.

|단계|상태|현재 근거와 다음 완료 조건|
|---|---|---|
|1. Flutter 및 Git 기반|완료(초기 구성)|Web·Android 프로젝트와 초기 Git 커밋, origin 설정 확인. 정적 분석·웹 빌드 성공 기록이 있다. 일반 PC Chrome 실행과 위젯 테스트 통과 기록은 별도 확인 대상이다.|
|2. Excel 원본 데이터 설계|진행 중|0.2.0은 검수 전이다. 0.9.0은 안내판 문항을 교체하고 역채점을 6·9·15번으로 줄인 파일럿이다. 번역·판정은 아직 draft/pending이다.|
|3. Python JSON 직렬화|완료(직렬화)|0.2.0 schema 1과 0.3.0 schema 2를 함께 생성한다. 같은 입력의 반복 생성, 실패 시 기존 파일 보존을 테스트했다. 두 버전의 출시 진단은 0개다.|
|4. Flutter 공통 엔진|완료(미리보기 파일럿)|응답 수정, 역채점, 독립 가중 평균, 12/20 판정을 위젯 없는 Dart로 구현했다. pending 규칙은 미리보기 세션만 실행한다. 출시 판정은 승인 전이라 막혀 있다.|
|5. 사이다 UI와 첫 진단|진행 중|기본 실행에서 0.9.0 인생 전술의 홈→문항→장면→결과→앱 안 공유 카드 미리보기를 연결했다. Chrome에서 대표 1회 완주, 카드 열기·닫기, 브라우저 뒤로 가기를 확인했다. 번역과 판정 승인은 아직이다.|
|6. 결과 및 공유|진행 중|결과 화면, 승인된 전술 이미지, 앱 안 공유 카드 미리보기까지 연결했다. 카카오톡·이미지 저장·공유 링크와 수신 경로는 아직 없다.|
|7. 글로벌 검증 및 출시|미착수|출시 언어 검수, 구버전 링크, 실제 기기와 브라우저 점검 후 배포.|

## 다음 작업
기본 실행은 0.9.0 미리보기에서 인생 전술을 홈부터 앱 안 공유 카드까지 진행한다. 카카오톡 전송, 이미지 저장, 공유 링크는 아직 없다. 다음 작업은 같은 버전의 응답에서 문항별 1~5 빈도와 장면별 선택 이유를 보고, 번역을 reviewed로 올린 뒤에만 판정 상태를 approved로 바꾸는 것이다. 출시 전환과 두 번째 진단 설계는 별도다.
