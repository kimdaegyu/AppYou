# Look At You UI Design System v1.0

라이트 테마의 디자인 기준은 **따뜻함 60% · 귀여움 25% · 깔끔함 15%**다. 세로형 모바일 화면에서 사이다가 사용자를 반기고, 응답하는 동안에는 질문과 선택지가 먼저 읽혀야 한다. 다크 테마는 별도 검토한다.

## 버튼과 카드

치수는 Flutter의 논리 픽셀 기준이다. 아래 높이는 기본 글꼴에서의 규격이며, 글자가 커지거나 두 줄이 되면 콘텐츠에 맞춰 늘린다.

| 구성 요소 | 배경 / 글씨 | 치수와 동작 |
| --- | --- | --- |
| Primary Button | primary / onPrimary | 높이 52, 반경 16, 글씨 16 SemiBold(600). 화면의 가장 중요한 동작에 사용하고 누르는 동안 primaryPressed 적용 |
| Secondary Button | highlight / textPrimary | 높이 48, 반경 16. 이전·다시 하기·다른 진단 |
| Text Button | 투명 / primary | 보조 동작. 주요 터치 영역은 최소 48 × 48 권장 |
| Disabled Button | 활성 상태와 구별되는 비활성 표현 | 포인터·키보드 실행을 모두 차단하고 보조 기술에도 비활성 상태를 전달 |
| 일반 카드 / 결과 카드 | surface / textPrimary | border 1, 반경 20 / 큰 결과 카드 24, 내부 여백 16~24 |

그림자는 최소화하고, 일반 영역은 여백으로 구분한다. 카드 안의 요소마다 테두리를 반복하지 않는다.

## 문항 화면과 사이다

- 모바일 콘텐츠 좌우 여백은 16~20, 질문은 20 SemiBold, 본문은 16이다. PC의 진단 콘텐츠는 중앙에 두고 기본 최대 너비를 520으로 한다.
- 답변은 세로로 배치한다. 높이는 최소 52, 답변 간 간격은 8~12다. 선택된 항목은 primary 테두리, surfaceVariant 배경과 선택 아이콘을 함께 사용하고 선택 상태를 스크린 리더에 전달한다.
- 진행 영역에는 높이 8의 primary 진행 막대, 현재/전체 문항 수, 사이다와 말풍선을 둔다. 작은 화면에서는 캐릭터 영역을 먼저 줄여 질문과 답변 공간을 확보한다.
- [승인된 사이다 v001 에셋](08_SAIDA_CHARACTER.md)의 크림색 털과 둥근 형태를 유지한다. 문항에 맞춰 표정·포즈를 바꾸고 대사는 Localization 키로 표시한다. 일반 문항에서는 반복 애니메이션을 줄이고, 절반 진행과 결과 공개에 연출을 집중한다. 모션 감소 설정에서는 정적인 표정과 대사로 같은 정보를 전한다.

## 결과 화면과 공유 이미지

시선은 타입명 → 핵심 문구 → 결과 이미지 순서로 유도한다. 진단별 시각화 템플릿은 달라도 버튼·카드·타이포그래피는 공통 규격을 쓴다.

| 인생 전술 성향 | 색상 토큰 | 축구 역할 |
| --- | --- | --- |
| 행복 | success | 수비수 |
| 삶의 의미 | info | 미드필더 |
| 심리적 풍요로움 | primary | 공격수 |

축 이름과 역할을 색과 함께 표시한다. 공유 이미지에서도 타입명과 핵심 문구가 털이나 경기장 그래픽에 묻히면 단색 surface 영역에 텍스트를 배치한다.

## 가독성과 구현 검수

일반 텍스트의 명도 대비 목표는 4.5:1 이상이다. 아래는 지정한 불투명 단색 쌍의 계산값이다.

| 글씨 / 배경 | 대비 |
| --- | ---: |
| onPrimary / primary | 5.84:1 |
| onPrimary / primaryPressed | 8.29:1 |
| textPrimary / highlight | 10.02:1 |
| textSecondary / background | 5.49:1 |
| textSecondary / surfaceVariant | 5.17:1 |

Cursor는 AppColors, AppTypography, AppSpacing, AppRadius를 한곳에서 관리하고 ThemeData와 공통 버튼·카드·진행률·문항 선택지 위젯에 연결한다. 화면별로 HEX를 반복 입력하지 않는다. 규격이 바뀌면 이 문서와 영향을 받는 컴포넌트를 함께 갱신한다.

구현 후 모바일 세로와 PC에서 긴 번역, OS 글꼴 확대, 키보드 포커스와 선택, 비활성 버튼, 모션 감소를 확인한다. 선택·성공·오류는 아이콘이나 텍스트로도 식별할 수 있어야 한다. 공유 이미지는 내보낸 결과물 크기에서 대비와 줄바꿈을 다시 확인한다.

## 글로벌 타이포그래피

사이다가 표정과 색으로 친근함을 전달하고 글꼴은 긴 질문을 편하게 읽도록 돕는다. 아래 값은 모든 언어와 모바일·PC에서 공유하는 기본 규격이다. 크기는 Flutter 논리 픽셀, 줄 높이는 글자 크기의 배수다.

| 역할 | 크기 | 굵기 | 줄 높이 | 사용 위치 |
| --- | ---: | ---: | ---: | --- |
| 대제목 | 28 | 700 | 1.3 | 첫 화면 제목 |
| 진단 질문 | 20 | 600 | 1.5 | 문항 본문 |
| 결과 타입명 | 24 | 700 | 1.4 | 결과 카드·공유 이미지의 별명 |
| 본문 | 16 | 400 | 1.6 | 답변 선택지·결과 설명·포메이션 설명 |
| 버튼 | 16 | 600 | 1.3 | 주요·보조 동작 |
| 사이다 대사 | 14~16 | 500 | 1.5 | 기본 16 권장, 작은 보조 말풍선은 14 |
| 보조 설명 | 14 | 400 | 1.5 | 진행률·힌트·공유 안내 |

언어별 패밀리는 [지역화 정책](05_LOCALIZATION.md)의 매핑을 따른다. 카드 자체는 글꼴을 고정하지 않고 내부 텍스트가 역할을 선택한다. 캐치프레이즈에는 대사 또는 본문 역할을 사용한다. 버튼은 최소 높이와 상하 여백을 두고 여러 줄을 수용한다. 긴 문구는 줄바꿈과 레이아웃 재배치로 처리한다. 320~360 너비와 200% 확대에서 말풍선·결과명이 잘리지 않아야 한다. OS TextScaler를 전달하고 작은 글자로 강제 축소하거나 고정 행 높이로 결합 부호를 자르지 않는다. 태국어·힌디어에서 실제 충돌이 재현되면 먼저 세로 여백과 줄 높이를 조정하고 예외를 기록한다.

공유 카드도 같은 locale·패밀리·역할·굵기를 사용한다. 고정 크기 이미지에서는 출력 배율을 적용한 뒤 결과 타입명, 포메이션 설명, 캐치프레이즈, 공유 안내의 실측 줄 수와 여백을 확인한다. 렌더러 선택은 후속 결정이다.
