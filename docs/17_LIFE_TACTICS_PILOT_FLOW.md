# 나의 인생 전술 첫 참여 흐름 기획서

2026-11-21 · 구현 전 기획. 목적은 첫 방문자가 진단을 발견하고, 자신의 응답으로 나온 전술과 긍정 설명을 읽고, 같은 결과의 공유 카드까지 확인하는 것이다.

## 회차 및 결과

- 한 회차에서 단계·현재 문항 ID·기본 응답·장면 응답·데이터 버전을 함께 유지한다. 이전에 선택한 답을 보여 주고, 변경하면 같은 문항의 응답을 교체한다. 언어를 바꿔도 같은 위치에서 계속한다.
- 기본 첫 문항의 이전은 시작 화면으로 연결한다. 같은 흐름에서 다시 진입하면 입력을 유지한다. 명시적인 ‘다시 하기’는 두 단계의 응답을 모두 비운 새 회차다. 같은 웹 탭에서는 새로고침 후에도 답변과 위치를 복원한다. [상세 기준](19_PILOT_REFRESH_AND_LAYOUT.md)
- 기본 응답으로 세 축 점수와 전술을 계산한다. 여섯 장면의 행동 점수는 별도 요약한다. 두 결과가 다른 사용자도 이해할 수 있게 장면 요약 바로 위에 이 차이를 설명한다. 기존 동점·경계 표시 규칙을 따른다.
- 전술판에는 위에서부터 공격·중원·수비를 배치한다. 예를 들어 4-2-4는 수비 4, 중원 2, 공격 4다. 점수 크기로 마커 개수를 정하지 않는다.

## 아트와 화면 검수

- [승인 아트 v001](../design/life_tactics/v001/)의 경기장, 전술판, 마커, 빈 공유 템플릿을 사용한다. tr03 한국어 완성 카드는 배치 검수 기준이다. 공유 미리보기는 다른 결과와 언어에도 대응한다.
- 결과 이미지와 공유 카드의 이미지 매핑을 공유한다. tr06·tr10은 D.C 로고 v003, 나머지는 v002다. [에셋 가이드](08_SAIDA_CHARACTER.md)
- 문항에서는 사이다와 대사가 선택지를 가리지 않도록 한다. 모바일 세로와 PC 중앙 콘텐츠 폭, 긴 번역 줄바꿈, 글자 확대, 키보드 선택을 확인한다.
- 완료 기준은 홈에서 18+6개에 실제 응답하여 결과와 같은 타입의 카드까지 도달하는 것이다. 언어 전환, 단계 경계에서 이전 이동 후 답 수정, 다시 하기까지 같은 흐름으로 검수한다.
